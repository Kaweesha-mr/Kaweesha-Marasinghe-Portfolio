# Kaweesha Marasinghe — Portfolio

A personal portfolio site for Kaweesha Marasinghe, built with Next.js, React, TypeScript, and the vinext Sites starter.

## Run locally

```bash
npm install
npm run dev
```

The site is available at `http://localhost:3000`.

## Verify

```bash
npm run lint
npm test
```

The public resume download lives at `/Kaweesha-Marasinghe-Resume-2.pdf`. Replace or add future campus-session, certificate, and research-presentation images under `public/images/` as they become available.
